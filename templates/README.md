# Templates Area

このディレクトリは、開発運用および報告等で使用する標準テンプレートを管理する領域です。

## テンプレート一覧
- `TASK_TEMPLATE.md`: PlannerからBuilderへ発行する標準タスク定義書テンプレート
- `PLANNER_REPORT_TEMPLATE.md`: BuilderからPlannerへ提出するHandoff ZIP内報告書 (`REPORT.md`) テンプレート
- `PLANNER_SESSION_HANDOFF_TEMPLATE.md`: Plannerブラウザセッション切替時の未永続化判断引継ぎテンプレート
- `SESSION_HANDOFF_TEMPLATE.md`: 汎用セッション引継ぎテンプレート

## 運用ルール
- テンプレート内の項目構造および利用方法については [TASK_RULES.md](../docs/development/TASK_RULES.md) および [SESSION_RULES.md](../docs/development/SESSION_RULES.md) を参照してください。
